- 已完成：
  1. 本机 WinRM 客户端配置（TrustedHosts 加入 10.99.70.90，AllowUnencrypted=true）——需管理员权限，通过 UAC 提权脚本完成；本机 WinRM 服务原本未运行，需先 Start-Service WinRM

  3. 授权模式设为 PerUser（Win32_TerminalServiceSetting.ChangeMode 参数名是 LicensingType 不是 Mode；注册表 HKLM:\SYSTEM\CurrentControlSet\Control\Terminal Server\RCM\Licensing Core\LicensingMode=4 双保险）
  4. 验证通过：TerminalServerMode=1（RDS 模式）、SingleSession=0、UserLimit 空（不限并发）
- 服务器上已有 21 个本地用户，17 人在 Remote Desktop Users 组
- 待办：120 天宽限期（约 2027-01-18）前需购买 RDS Per-User CAL；建议改 administrator 密码（已在对话中暴露）
- 排障经验：WinRM Negotiate 认证报 0x8009030e 时，把目标 IP 加入 TrustedHosts 即可；Basic 认证需服务端 AllowUnencrypted，该服务器只支持 Negotiate
- 后续问题：用户连接报「远程桌面许可证出现问题，会话将在60分钟后断开」。根因：GracePeriod 注册表键（HKLM:\SYSTEM\CurrentControlSet\Control\Terminal Server\RCM\GracePeriod）下无宽限期记录（疑似镜像系统残留），授权服务判定无许可证且无宽限期
- 修复：该键仅 SYSTEM 可删，通过注册 SYSTEM 计划任务执行 Remove-Item + Restart-Service TermService，删除后系统重建 120 天宽限期；临时计划任务已清理
- 待办更新：宽限期从修复时刻重新计算，约 2027-01-18 前需购买 RDS Per-User CAL
- 第二轮修复（用户反馈重启后仍报许可证错误）：
  - SYSTEM 权限诊断发现：GracePeriod 容器存在但子键数为 0（完整重启后仍未写入宽限期记录，疑似克隆镜像母盘已耗尽宽限期）；事件 ID 50282「会话主机没有指定授权服务器」
  - 处置：安装 RDS-Licensing 角色（TermServLicensing 服务已运行）；通过策略注册表 SpecifiedLicenseServers/LicenseServers 指定本机 10.99.70.90 为授权服务器；重启 TermService 后 50282 不再出现
  - 排障经验：Win32_TerminalServiceSetting 的 WMI 方法参数名与直觉不符（ChangeMode 用 LicensingType，AddDirectConnectLicenseServer 无 LicenseServer 参数），改用策略注册表 HKLM:\SOFTWARE\Policies\Microsoft\Windows NT\Terminal Services 更可靠；SMB 管理共享（C$）在该服务器被禁用，传文件走 WinRM 会话 Set-Content；GracePeriod 键仅 SYSTEM 可读，需注册 SYSTEM 计划任务执行诊断/删除
